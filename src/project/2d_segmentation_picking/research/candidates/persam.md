# PerSAM / PerSAM-F

> 담당 토픽: topics/dino-backbone.md · 작성일: 2026-10-29

## 요약

레퍼런스 1장 + 마스크로 SAM을 "개인화"해 다른 이미지에서 같은 대상을 분할(2023). 학습 없는 PerSAM과 2개 파라미터를 10초 학습하는 PerSAM-F. DINO가 아니라 SAM 자체 특징으로 위치 prior를 만든다. 비교 기준용.

## 분류

| 항목 | 값 |
|---|---|
| 파이프라인 유형 | [PM] 변형(레퍼런스 → 자동 프롬프트) |
| 입력 모달리티 | [RGB] |
| 맞는 시나리오 | [ONE] 일부 — 기본은 단일 대상, 같은 카테고리 다중 객체는 커뮤니티 기여 스크립트(`persam_f_multi_obj.py`) (확인) |
| 프롬프트 | 예시 이미지 1장 + 마스크 |
