# L2G-Det (Local-to-Global novel instance detection)

> 담당 토픽: topics/dino-backbone.md · 작성일: 2026-10-29

## 요약

NIDS-Net 연구실(UT Dallas IRVL)의 후속(arXiv 2603.03577, 2026.3). 마스크 제안을 생략하고 **DINOv3-L 패치 대응**으로 후보 점을 찾은 뒤, 물체별 학습 토큰을 넣은 SAM 디코더로 전체 마스크를 복원. 제안기 품질(우리 m1 과분할 문제)에 의존하지 않는 구조라 주목할 만하지만 코드 공개가 미확인.

## 학습 데이터

라벨 사진은 레퍼런스 소수뿐이지만, 레퍼런스를 배경에 합성한 **물체당 500장**으로 adapter(20 epoch)와 객체 토큰(12 epoch)을 학습(확인). 사람 라벨링은 거의 없음.

## 성숙도

- 2026.3 프리프린트, 코드 공개 여부 미확인.

## 기준선(m1/m2) 대비

- 기대 이점: HR-InsDet AP 76.2 vs NIDS-Net 63.9, RoboTools 71.9 vs 64.9 (확인). 과분할된 제안을 거치지 않음.
- 위험: 코드 미확인, 물체별 학습 단계, DINOv3 라이선스.
