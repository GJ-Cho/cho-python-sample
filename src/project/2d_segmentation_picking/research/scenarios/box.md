# [BOX] 팔레트 디팔레타이징 — 박스 1종 / 2종 / 3종

> 통합: 2026-10-29 · 근거 문서: `topics/detectors.md`, `topics/segmenters.md`, `topics/input-modality.md`, `evaluation.md`, `data/dataset-plan.md`
> 표기: **확인** = 출처 있음(근거 문서 또는 직접 검증), **(추론)** = 근거는 있으나 미검증

## 시나리오 정의

- 팔레트 위에 층층이 쌓인 박스를 위에서 촬영한다. 최상층 박스를 낱개 마스크로 나누는 것이 목표다.
- 하위 조건: **1종**(같은 박스만), **2종 혼합**, **3종 혼합**. 1종이 가장 어렵다. 같은 무늬 박스가 빈틈없이 붙으면 경계 단서가 테이프·인쇄·틈 그림자뿐이다(추론).
- 주지표: P@K(K=1,3,5, IoU≥0.75) + **merge 수**(박스 두 개를 한 마스크로 합친 수). 정의는 `evaluation.md` 1장.

## 추천

| 순위 | 방법 | 유형 | 학습 | 라이선스 | 4060L 속도 (추론) |
|---|---|---|---|---|---|
| 1 (운영) | **RF-DETR-Seg S/M** | [E2E] | 라벨 수백 장(실측 + 합성) | Apache-2.0, Seg 전 크기 (직접 확인) | 수십 ms |
| 2 (학습 없이 / 라벨 생성) | **SAM3** 텍스트 "box" + 장면 안 예시 박스 1~3개 | [E2E] 개념 분할 | 없음 | SAM License(비표준, 법무 확인) | 텍스트 1개당 0.3~0.6s |
| 3 (최소 비용 비교) | MM-Grounding-DINO / LLMDet → SAM2.1 | [DS] | 없음 | Apache-2.0 (O365 약관 주의) | m2와 비슷 (~1s) |
| 기준선 | m2 (Grounding DINO tiny → SAM2.1) | [DS] | 없음 | Apache-2.0 | 0.8~1.2s |

**권장 흐름 (추론):** SAM3로 자동 라벨 → 사람이 검수 → RF-DETR-Seg 학습 → 운영. SAM3는 같은 이미지 안의 예시 박스만 받으므로(확인), "장면에서 박스 하나를 찍어 주면 같은 박스 전부"라는 [BOX] 흐름에 잘 맞는다.

라이선스 감점: YOLO-seg / YOLOE(AGPL), YOLO-World(GPL).

## 입력 모달리티

| | 판단 | 근거 |
|---|---|---|
| [RGB] | 기본 | 경계는 테이프·인쇄·틈 그림자가 결정 (추론) |
| [RGB-D] | 같은 높이 밀착에서는 이득 작음, **층 분리·높이 혼합 팔레트에서 유효** | Box-IS: RGB 83.3 → RGB-D 83.7 AP (확인. 단 RealSense D455 촬영·저자 주장치, 독립 검증 없음) |
| [RGB-D-N] | 모서리 라운드가 법선맵에 선으로 보이는지 **증거 없음** | 3단계 실측 1순위 항목 |

- **경고 (확인):** m1의 평면 병합(법선 각도차 + offset)은 같은 높이에 붙은 물체를 합친다. scene03 원통 2개가 `merged_from: 3`으로 합쳐진 사례가 있다. [BOX]에서는 병합을 끄거나 경계 엣지 검사를 붙여야 한다.
- 모달리티보다 **직사각형 + 크기 사전정보 피팅**으로 합쳐진 마스크를 쪼개는 쪽이 효과적일 수 있다(추론).

## 데이터 (`data/dataset-plan.md` 5장)

- 테스트: 1/2/3종 × 30장 = 90장. 그중 학습에 없는 박스 30장.
- 학습: 실측 150~200장 + BlenderProc 합성 2,000~5,000장(추론).
- 상용 가능한 공개 박스 데이터셋은 찾지 못했다. SCD는 비상업, Box-IS는 라이선스 표기 없음(확인).

## 3단계에서 확인할 것

1. SAM3가 같은 무늬 밀착 박스를 낱개로 나누는가, 한 덩어리로 묶는가
2. SAM3의 4060L 속도와 VRAM (별도 venv, torch 2.7+ 필요)
3. [RGB-D-N] 법선맵이 같은 높이 박스 사이의 틈을 보여주는가
4. 합성으로만 학습한 RF-DETR-Seg가 실제 Zivid 이미지에서 얼마나 떨어지는가
