# CLAUDE.md — 2D Segmentation Picking Demo

이 폴더는 Zivid 카메라 + UR3e 로봇으로 **언논 오브젝트(unknown object)를 2D 세그멘테이션 기반으로 피킹하는 데모** 프로젝트다.

## 시작 전 반드시 할 일

1. **`PLAN.md`를 먼저 전부 읽는다.** 설계 결정과 그 근거, 폐기된 대안, 미결 질문이 모두 정리되어 있다.
2. 상위 `AGENT.md`의 Zivid 작업 규칙(공식 문서/공식 GitHub 우선, API 임의 생성 금지)을 그대로 따른다.
3. `PLAN.md`의 "미결 질문" 항목이 비어 있지 않으면, 코드 작성 전에 사용자에게 확인한다.

## 작업 규칙

- Python 3.11 기준. **단일 venv 환경**에서 모든 방법이 동작해야 한다. 별도 환경을 요구하는 라이브러리는 채택하지 않는다.
- Zivid API 이름을 추측해서 만들지 않는다. 불확실하면 `zivid-python-samples` 레포를 확인하거나 사용자에게 묻는다.
- 3가지 방법(m1/m2/m3)은 반드시 `methods/base.py`의 `Segmenter` 인터페이스를 공유한다. 한 방법의 구현이 다른 방법의 코드에 침범하지 않게 한다.
- 기하 판정(높이, 기울기)은 **카메라 좌표계가 아니라 빈 좌표계(bin frame)** 에서 수행한다. 이유는 `PLAN.md` 4장 참조.
- 하드코딩 금지. 임계값은 전부 `config/*.yaml`로 뺀다.
- 주석과 문서는 한국어, 코드 식별자와 API 이름은 영어.

## 진행 상황

- 2026-07-27: `PLAN.md` 8장 미결 질문 **전부 확정**(GPU/인터넷/카메라 각도·모델/빈 깊이/그리퍼/프롬프트/사이클 타임). 엔드이펙터가 석션→**핑거 그리퍼**로 변경됨(세그멘테이션 우선, 파지 로직은 그리퍼 확정 후 재설계).
- Phase 0 착수 가능 상태. `PLAN.md`의 Phase 표를 진행 상황 추적에 사용하고, 완료 시 해당 행을 갱신한다.

## 협업 제약

- 웹 채팅 세션의 Claude는 Zivid SDK가 없어 `.zdf`를 직접 파싱할 수 없다. 따라서 `scripts/inspect_zdf.py`가 씬 통계를 **JSON 텍스트로** 출력하도록 만들어, 그 결과를 사람이 공유하는 루프를 전제로 설계한다.
- Claude Code는 로컬에서 직접 실행 가능하므로 이 제약이 없다. 실행 결과를 직접 확인하고 파라미터를 조정할 것.
